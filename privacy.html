Hermes Privacy Policy

Effective date: 2026-10-11

1. Who uses this app

Hermes is a personal assistant app used only by its owner, JIARUI LI. It is not offered to the public. The only Google account data it accesses is the owner's own data.

2. Data we access

With the owner's authorization via Google OAuth, Hermes may access the owner's own Google account data from Gmail, Google Calendar, Google Docs, Google Sheets, Google Drive, Google Contacts, and Google Tasks.

3. How data is used

Data accessed via Google APIs is used solely to provide the owner's personal assistant features, such as reading, summarizing, organizing, and acting on the owner's email, calendar, documents, contacts, and tasks at the owner's request.

4. Sharing and transfer

Data is not sold, shared, or transferred to third parties, except as needed to process requests via the owner's chosen AI model provider (DeepSeek) at the owner's request. Data is never used for advertising.

5. Storage

Data is stored only on the owner's private servers and in the owner's own Google Drive.

6. Advertising

Hermes does not display advertising and does not use Google user data for advertising, retargeting, or interest-based ads. Hermes contains no tracking or analytics.

7. Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Specifically: Google user data is used only to provide or improve user-facing features of Hermes; it is transferred to others only as necessary to provide those features, to comply with applicable law, or as part of a merger, acquisition, or sale of assets with notice to the user; it is not used for serving advertisements; and no human reads it except with the owner's affirmative consent, for security purposes, to comply with applicable law, or where the data is aggregated and anonymized for internal operations. Google user data is not used to develop, improve, or train generalized AI or machine learning models.

8. Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Hermes 隐私政策

生效日期：2026-10-11

1. 使用者

Hermes 是一款个人助理应用，仅供其所有者 JIARUI LI 本人使用，不向公众提供。本应用仅访问所有者本人的 Google 账户数据。

2. 访问的数据

经所有者通过 Google OAuth 授权，Hermes 可访问所有者本人在 Gmail、Google 日历、Google 文档、Google 表格、Google 云端硬盘、Google 通讯录和 Google 任务中的数据。

3. 数据用途

通过 Google API 访问的数据仅用于为所有者提供个人助理功能，例如应所有者的请求阅读、总结、整理和处理其邮件、日历、文档、联系人和任务。

4. 共享与转让

数据不会被出售、共享或转让给任何第三方，但应所有者请求、为处理其请求而需要发送至所有者选择的 AI 模型提供商（DeepSeek）的情况除外。数据绝不用于广告。

5. 存储

数据仅存储在所有者的私人服务器以及所有者本人的 Google 云端硬盘中。

6. 广告

Hermes 不展示广告，也不将 Google 用户数据用于广告、再营销或基于兴趣的广告。Hermes 不包含任何跟踪或分析工具。

7. Google API 服务用户数据政策

Hermes 对从 Google API 获取的信息的使用以及向任何其他应用的转移，均将遵守 Google API 服务用户数据政策，包括其中的“有限使用”（Limited Use）要求。具体而言：Google 用户数据仅用于提供或改进 Hermes 面向用户的功能；仅在提供这些功能所必需、遵守适用法律，或在通知用户的前提下涉及合并、收购或资产出售时才会转移；不用于投放广告；除非获得所有者的明确同意、出于安全目的、为遵守适用法律，或数据经汇总和匿名化用于内部运营，否则任何人都不会阅读这些数据。Google 用户数据不会用于开发、改进或训练通用人工智能或机器学习模型。

8. 撤销访问权限

可随时在 https://myaccount.google.com/permissions 撤销访问权限。
